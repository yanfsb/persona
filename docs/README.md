# Persona documentation

Persona is a release candidate. These documents describe the current bounded implementation, not a general security or isolation guarantee.

## Using Persona

1. [Install Persona and its native prerequisites](installation.md).
2. [Follow the safe getting-started flow](getting-started.md).
3. Read the [configuration reference](configuration.md) and [CLI reference](cli.md).
4. Check the exact [managed command surface](managed-commands.md) and [security model](security-model.md) before enabling adapters.
5. If something fails, see [troubleshooting](troubleshooting.md).
