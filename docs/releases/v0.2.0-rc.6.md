# Persona v0.2.0-rc.6

Release candidate adding policy-controlled support for multiple Git SSH hosts and opt-in HTTPS credential helpers for non-GitHub forges.

## Changes since v0.2.0-rc.5

- **Multi-host SSH transport policies**: profiles can define additional exact SSH host/user/port policies with `[[profiles.ssh_hosts]]`, allowing managed Git operations to use more than one SSH forge while retaining explicit key and host-key checks.
- **Opt-in external HTTPS credential helpers**: profiles can delegate HTTPS credential requests for explicitly configured non-GitHub hosts with `[[profiles.https_credentials]]`. Persona checks configured fetch/push destination policy before invoking the helper, invokes it without a shell, and does not store credentials. GitHub hosts remain bound to Persona's existing GitHub account policy.
- **Host-scoped GitHub push-binding checks**: GitHub account binding is required for GitHub destinations and the configured bound host, without incorrectly requiring GitHub binding for other explicitly allowed forges.

## Validation

- Synthetic tests cover configuration validation, managed SSH host selection, external HTTPS credential-helper allow/deny behavior, and GitHub binding boundaries.
- Local checks (`just check` and `just build`) verify formatting, Rust 1.85 MSRV compatibility, Clippy (`-D warnings`), documentation links/examples, and locked tests.
- Hosted CI must pass on Linux x86_64, Linux arm64, and macOS arm64 for the exact final commit before tagging.
