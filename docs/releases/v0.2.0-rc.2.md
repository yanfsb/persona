# Persona v0.2.0-rc.2

This release candidate improves Persona's daily CLI ergonomics and compatibility against [clig.dev](https://clig.dev/) guidelines without weakening any identity, signing, destination, or credential separation invariants. It is not a stable release or a production security boundary.

## Changes since v0.2.0-rc.1

- **Universal `git` / `gh` version & help compatibility**: Allowed `git --version`, `git -v`, `git version`, `git --help`, `git -h`, `git help`, `git -P` (`--no-pager` short flag), and `gh --version` / `--help` / `help` / `completion` cleanly both inside and outside managed scopes (while respecting explicit profile denylists inside a scope and never exposing tokens to `gh` help/version calls).
- **Accurate diagnostic exit codes & visible blockers**: Healthy managed Git worktrees now exit `0` (`PASS`) on `persona`, `persona status`, and `persona doctor` even when offline network/ambient indicators remain `UNKNOWN` (add `--strict` to exit `3`/`4` on informational unknowns/warnings; unmanaged directories continue exiting `3`). Non-verbose `persona check` now prints authorization blockers directly instead of hiding them behind `--verbose`.
- **Human-readable errors & preserved child environment**: Implemented `Display` across configuration, storage, path, and credential errors instead of leaking raw Rust `Debug` structs. Preserved `NO_COLOR`, `CLICOLOR`, `CLICOLOR_FORCE`, `COLORTERM`, `PAGER`, `GIT_PAGER`, `LESS`, `GPG_TTY`, `TMPDIR`, `TERM`, `LANG`, `LC_ALL`, and `EDITOR` for managed `git` and `gh` child invocations.
- **CLI consistency & mutation ergonomics (`clig.dev`)**:
  - Documented all top-level commands, subcommands, and options in `--help`, added `EXAMPLES` + repository docs link, grouped `profile add|update` flags by heading, and separated `StatusArgs` from `CheckArgs`.
  - Honored `PERSONA_CONFIG_PATH` in `resolve_config_path`, added `--config` to `scope list|show|verify`, added `-n` / `--dry-run` aliases alongside `--preview`, added `--no-color` and `-q` / `--quiet`, added `--json` to `profile list|show`, `scope list|show`, and `auth verify`, and added `persona completions <bash|zsh|fish>` (plus `persona shell completions`).
  - Made `persona profile update` preserve omitted `author_*` / `committer_*` and `ssh_*` fields and added `--clear-signing`; separated offline `scope show` from on-disk `scope verify`; added `--no-input` and committer defaults on `persona setup`.
- **`SIGINT`-safe child waiting**: Added `wait_child_ignoring_sigint` around child processes (`persona run`, managed `git`, `gh`, `ssh`) so `Ctrl-C` cleans up temporary shim/home/handoff directories cleanly.

## Validation

- Local checks (`just check`, `cargo build --locked --release`, and macOS `nix flake check`) verify formatting, Rust 1.85 MSRV compatibility, Clippy (`-D warnings`), documentation links/examples, and locked synthetic tests across all suites.
- Before tagging, hosted CI must pass on Linux x86_64, Linux arm64, and macOS arm64 for the exact final commit. Publish the final commit/run/asset verification evidence in the GitHub prerelease record.

## Limitations

Persona mediates only managed PATH shims, `persona run`, and installed `pre-push` hooks; direct native executables, `--no-verify`, and same-user processes remain outside its boundary. See the [CLI reference](../cli.md), [managed commands](../managed-commands.md), and [security model](../security-model.md).
