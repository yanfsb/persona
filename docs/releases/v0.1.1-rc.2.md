# Persona v0.1.1-rc.2

This follow-up patch release candidate broadens guarded ordinary Git workflows while keeping unsupported managed operations fail-closed. It is a release candidate, not a production security boundary.

## Changes

- Support bounded LazyGit-compatible fetch and push forms, including default fetch/push target resolution and same-name push refspecs; ambiguous or unsupported forms remain blocked.
- Support `git fetch --all` by preflighting every eligible remote and its exact configured destination before any transport, honoring `remote.<name>.skipFetchAll`, configured fetch refspecs, and managed per-remote HTTPS or SSH transport.
- Preserve aggregate `FETCH_HEAD` behavior across per-remote fetches. Cross-remote transfers are not atomic: a runtime failure may occur after earlier remotes have fetched. Recursive submodule fetching is disabled, and pruning is only performed when explicitly requested.
- Add optional per-profile Git command allowlists and denylists. Missing allowlists preserve the current supported surface, empty allowlists deny all, and denylists take precedence; these policies cannot enable unsupported native pass-through or bypass Persona checks.
- Treat commits already ancestral to the exact destination-bound pinned upstream baseline as existing history for identity and signature checks; newly introduced commits still require the selected local signer.
- Authorize HTTPS credential-helper requests against fetch destinations for fetch and push destinations for push.

## Validation

- `cargo fmt --all -- --check`, locked all-target `cargo check`, locked all-target Clippy, and documentation tests passed locally.
- `cargo test --locked --all-targets --features test-support` passed locally across all 21 suites using synthetic fixtures.
- Hosted CI on Linux x86_64, Linux arm64, and macOS arm64 for the exact candidate commit is required before publication.
- No real managed GitHub publication is exercised by these synthetic tests.

## Limitations

Persona mediates only documented managed paths; direct native binaries and hostile same-user processes remain outside its boundary. Unsupported operations fail closed. A limited real-account pilot verified account binding, repository metadata reads, and SSH fetch only; managed publication and production use have not been exercised. See the [security model](../security-model.md), [managed commands](../managed-commands.md), and [release procedure](../releasing.md).
