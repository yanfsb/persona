# Persona v0.2.0-rc.5

Hotfix release candidate fixing HTTPS `git push` / `fetch` / `pull` / `clone` failures (`Git HTTPS credential request denied`) when `gh auth token` needs the user's real `HOME` (for example macOS Keychain at `~/Library/Keychains`).

## Changes since v0.2.0-rc.4

- **`PERSONA_REAL_HOME` for credential helper lookups**: `run_managed_git` and `execute_managed_fetch_all` in `src/git_adapter.rs` continue isolating Git itself with a temporary `HOME` and `GIT_CONFIG_GLOBAL=/dev/null`, while passing `PERSONA_REAL_HOME` so `GithubSelector::discover` in `src/credential.rs` preserves real `HOME` for native `gh auth token` keyring/keychain access.

## Validation

- Local checks (`just check`, `cargo build --locked --release`, and macOS `nix flake check`) verify formatting, Rust 1.85 MSRV compatibility, Clippy (`-D warnings`), documentation links/examples, and locked synthetic tests across all suites.
- Hosted CI must pass on Linux x86_64, Linux arm64, and macOS arm64 for the exact final commit before tagging.
