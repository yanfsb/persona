# Persona v0.2.0

First stable release of Persona, consolidating all `0.2.0-rc.*` capabilities with a redesigned, concise **configuration schema v4** and improved CLI ergonomics.

## Breaking changes

- **Configuration schema v4 (`version = 4`)**: Replaces legacy v1/v2/v3 formats with named `[profiles.<name>]` tables, explicit profile inheritance (`extends`), inline `scopes` (plus optional top-level `[scopes]`), flat `name`/`email` identity shorthand, unified `[profiles.<name>.git]` destinations/push/remotes with forge shorthands (`github.com/OWNER/*`), multi-host `[profiles.<name>.ssh]` with sensible defaults, `[profiles.<name>.https."<host>"]`, and `[profiles.<name>.github.merge."<owner/repo>"]`. Legacy v1/v2/v3 config parsers and `persona config migrate` have been removed.

## Highlights since v0.2.0-rc.6

- **Concise configuration schema v4 (`version = 4`)**:
  - Named profile tables (`[profiles.<name>]`) with explicit `extends = "<parent>"` inheritance (scalars inherit, lists replace so child profiles can narrow permissions, cycles and missing parents fail closed).
  - Inline `scopes = ["~/dir"]` or named `{ name, path }` entries directly on profiles, plus deterministic `~/` expansion against validated `$HOME`.
  - Forge shorthands (`github.com/OWNER/*`, `github.com/OWNER/REPO`) that expand to both SSH and HTTPS while explicit protocol URLs remain protocol-scoped.
  - Sensible SSH defaults (`user = "git"`, `port = 22`, `known_hosts_file = "~/.ssh/known_hosts"`, `public_key = "<identity_file>.pub"`), multi-host `hosts = [...]`, and automatic `signing.format` inference.
  - Default-omitting serialization and preservation of authored `extends`, `~/`, and forge shorthands across CLI mutations (`baseline update`, `auth enroll`, `profile update`).
  - Actionable TOML parse errors reporting exact line/column/field details.
- **New `persona config` ergonomics**:
  - `persona config path`, `persona config validate`, `persona config show [--profile NAME] [--resolved] [--json]`, and `persona config edit` (private `0600` temp buffer in `$VISUAL`/`$EDITOR` with pre-save validation, atomic write, and automatic backup).
  - `persona profile add/update --extends` and richer `persona profile show` output.
- **Git & GitHub workflow improvements**:
  - Bare `--force-with-lease` and `--force-with-lease=<ref>` automatically resolve cached remote-tracking OIDs into exact leases verified at both primary authorization and the `pre-push` hook.
  - Opt-in `allow_force_push = true` support while retaining commit identity/signing audits and command denylist precedence.
  - Managed `gh repo create` and `gh repo clone` target directory resolution and repository allowlist enforcement.

## Validation

- Local validation via `just check`, `just build`, and `nix flake check` (formatting, Rust 1.85 MSRV, Clippy `-D warnings`, documentation links/examples, locked unit/integration tests, and installed smoke checks).
- Hosted CI required to pass on Linux x86_64, Linux arm64, and macOS arm64 for the exact release commit before tagging and publication.
