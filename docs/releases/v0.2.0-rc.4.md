# Persona v0.2.0-rc.4

Hotfix release candidate fixing `git pull` failing with `error: unknown option 'no-prune-tags'`.

## Changes since v0.2.0-rc.3

- **`git pull` flag compatibility**: Separated `managed_pull_safety_arguments` from `managed_fetch_safety_arguments` in `src/git_adapter.rs` so `git pull` receives `--no-prune` (unless `--prune` / `-p` is given) and `--no-recurse-submodules`, without injecting `git fetch`-only `--no-prune-tags` (tag pruning remains disabled via `-c fetch.pruneTags=false`).
- **Regression test**: Added `git pull` end-to-end integration test in `tests/cli.rs` and unit coverage in `src/git_adapter.rs`.

## Validation

- Local checks (`just check`, `cargo build --locked --release`, and macOS `nix flake check`) verify formatting, Rust 1.85 MSRV compatibility, Clippy (`-D warnings`), documentation links/examples, and locked synthetic tests across all suites.
- Hosted CI must pass on Linux x86_64, Linux arm64, and macOS arm64 for the exact final commit before tagging.
