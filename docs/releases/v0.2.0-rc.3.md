# Persona v0.2.0-rc.3

Hotfix release candidate for `v0.2.0-rc.2` enabling `--git-dir` / `--work-tree` scope-verified handling and native passthrough in unmanaged directories (such as Neovim plugin managers and editors).

## Changes since v0.2.0-rc.2

- **`--git-dir` & `--work-tree` support**: Parsed `--git-dir` and `--work-tree` global Git options in `GitInvocation::parse`, canonicalizing their targets in `run_managed_git`. Within managed scopes, both must resolve to the same Persona scope (cross-scope or external `--git-dir` redirects remain blocked).
- **Unmanaged directory passthrough**: When a Git invocation's resolved worktree and `--git-dir` both lie outside every configured Persona scope (for example `~/.local/share/nvim/lazy/blink.cmp` or `/tmp`), `persona` delegates cleanly to native `git` instead of exiting `126`, while still enforcing full guardrails whenever targeting any configured scope.

## Validation

- Local checks (`just check`, `cargo build --locked --release`, and macOS `nix flake check`) verify formatting, Rust 1.85 MSRV compatibility, Clippy (`-D warnings`), documentation links/examples, and locked synthetic tests across all suites.
- Hosted CI must pass on Linux x86_64, Linux arm64, and macOS arm64 for the exact final commit before tagging.
